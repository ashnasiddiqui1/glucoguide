# Demo video script (3–5 minutes)

Record the deployed application in a browser. Use a fresh synthetic account and synthetic records only.

1. **Opening — 20 seconds:** “GlucoGuide helps adults living with diabetes organize readings, schedules, meals, activity, and reports in one private place. It is a tracker, not a medical advice tool.”
2. **Account and dashboard — 35 seconds:** Register or sign in. Point out the personalized, initially empty dashboard and the safety disclaimer.
3. **Glucose workflow — 60 seconds:** Add two readings with different contexts. Filter the history, edit one, and show the chart and saved target-range notice. Explain that the notice uses the user's own saved range and does not prescribe treatment.
4. **Medication workflow — 45 seconds:** Create a schedule with a user-entered instruction and a time. Show the upcoming event, then mark it taken or skipped. Refresh to demonstrate the status remains saved.
5. **Journal and reporting — 45 seconds:** Add a meal and an activity. Open Trends & reports, change the date range, show statistics calculated from saved readings, and download CSV.
6. **Engineering close — 30 seconds:** Briefly show the README or GitHub repository. Mention password hashing, HTTP-only sessions, server-side ownership enforcement, validation, tests, and persistent deployment storage.

Before recording, rehearse the flow, enlarge the browser window, and remove any personal data, secrets, or irrelevant tabs from view.
